Introduction to HTML

This is a simple introduction to HTML.

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language for creating web pages.

Basic Structure of an HTML Document

An HTML document has a basic structure that includes the following elements:

  • <!DOCTYPE html>: Declares the document type.
  • <html>: The root element of an HTML page.
  • <head>: Contains meta-information about the document.
  • <body>: Contains the content of the document.

Example of a Simple HTML Document

<!DOCTYPE html>
<html>
<head>
    <title>Page Title</title>
</head>
<body>
    <h1>My First Heading</h1>
</body>
</html>

Types of Lists

There are three main types of lists in HTML:

  1. Ordered lists (<ol>)
  2. Unordered lists (<ul>)
  3. Description lists (<dl>)

Ordered Lists

Ordered lists are used when the order of items is important. They are created using the <ol> tag.

Unordered Lists

Unordered lists are used when the order of items is not important. They are created using the <ul> tag.

Description Lists

Description lists are used to define terms and their descriptions. They are created using the <dl> tag.

Divs are used for grouping HTML elements

The <div> tag is a block-level element that is used to group other HTML elements together. It does not have any semantic meaning, but it can be styled using CSS.
